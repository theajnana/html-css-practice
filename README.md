# Jude Community Hospital: Patient Registration form
A patient registration and medical history form  for a demo hospital, built with HTML and CSS as a practice project. it uses demo data only and does not store or send any information.
## What's on this form
- **Personal informatiom:** name ,date of birth,age, sex, email, phone, address, occupation
- **Medical details:** blood ype, insurance, department, pain level slider, pre-existing conditions, reason for visit
- **Appointment and document:** Preffered date and time, ID upoad,prffered contact method
- **Consent checkbox** that must be ticked before submitting.
# uilt with
- HTML
- CSS(Flexbox,gradient, responsive layout for phones)
## How to view
Download the project and open form.html in your browser.
